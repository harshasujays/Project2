# Academic Manager

Academic Manager is a Java-based console application designed to manage and analyze student academic records efficiently.

It allows users to store student details, manage multiple subjects, calculate weighted scores, apply grading schemes, and generate detailed performance reports.

---

## Features

- Add and manage student records
- Multiple subjects per student with credit system
- Weighted average calculation based on credits
- Multiple grading schemes (School, University, CBSE, Custom)
- Update student marks and grading rules
- Search students by name or roll number
- Sort students by marks or name
- Class-level statistics (top, lowest, pass/fail count)
- Subject-wise performance analysis
- Grade distribution report
- Remove student records
